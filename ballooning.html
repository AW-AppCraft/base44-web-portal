Before you submit a FAIR with this

  • Extraction is an accelerator, not an authority. AS9102 makes the supplier responsible for characteristic accountability — every balloon still needs a human check against the print.
  • Basic dimensions cannot be detected from text alone. The box around a basic dimension is drawing geometry, not text, so untoleranced dimensions are flagged for review rather than guessed at.
  • Drawings using legacy CAD symbol fonts (gdt.shx and relatives) map GD&T glyphs onto ASCII letters. Those frames are remapped best-effort and always flagged — verify the mapping on a known drawing first.
  • Scanned drawings have no text layer. Nothing will be extracted; use manual ballooning or pre-process the file with OCR or a vision model.
