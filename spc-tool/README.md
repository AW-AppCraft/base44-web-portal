# SPC Calculator v13 — all-in-one SPC tool

Rebuild of `SPC_Calculator_v12.1.xlsx`. Everything is generated by
`build_spc_v13.py`, so the workbook can be regenerated at any time:

```bash
python3 build_spc_v13.py SPC_Calculator_v13.xlsx
```

Files:

| File | What it is |
|---|---|
| `build_spc_v13.py` | Build script — the single source of truth for the workbook |
| `SPC_Calculator_v13.xlsx` | The generated workbook |
| `SPC_V13_Monitor.bas` | VBA module: folder watch, auto-import, refresh, kiosk mode |
| `validate_v13.py` | Static checks on the generated workbook (see *Validation* below) |

## What changed from v12.1

| Request | How it was done |
|---|---|
| Data range shown to the left of the graphs | Every chart band on **Control Charts** and **Monitor** starts with a statistics panel in columns A–B: min, max, **range**, mean, median, std dev, sigma-within, control limits, spec limits, Cp/Cpk/Pp/Ppk and a verdict. Charts start at column D, so the numbers and the picture read together. |
| USL/LSL visible on the X charts | Each X chart now carries six series: X, CL, UCL, LCL, **USL**, **LSL**. Spec limits are purple long-dash, so they never get confused with the red control limits. Blank spec limits simply produce no line (`NA()`), and `Settings!F7 = N` hides them without deleting them. |
| Histograms | One histogram per feature on Control Charts, per slot on Monitor, and one on Visual SPC that follows the filters. Bin count is `Settings!F6`. The bin range is stretched to cover LSL and USL, and purple spikes mark the bins holding each spec limit — so you see the distribution against the tolerance, not just against itself. |
| Printable data collection sheet | New **Data Collection Form** sheet: job header fields, a characteristics block that pulls nominal/LSL/USL/unit straight from Settings, 25 numbered blank rows × 10 characteristics, notes and signature blocks. Print area, A4 landscape, fit-to-one-page and repeating headers are all preset — Ctrl+P and go. |
| Folder monitoring + self-updating graphs | `SPC_V13_Monitor.bas`. Point `Settings!F8` at a folder, set a pattern in `F9`, run `SPC_StartMonitor`. New files are appended to Data Entry, every chart is refreshed, and the Monitor sheet logs status, last scan, files/rows imported and any error. Already-imported files are tracked on a hidden `_ImportLog` sheet so nothing is double-counted. |
| Share on screen | `SPC_KioskMode` goes full screen and cycles through the four Monitor slots every `Settings!F13` seconds. `SPC_KioskStop` exits. |
| Filters and plots | **Visual SPC**: feature, date-from, date-to, shift, operator and tool filters drive a filter engine (hidden `_Calc` sheet) that recomputes n, mean, range, control limits, Cp/Cpk **and** all three plots from the filtered subset only. |
| One tool for SPC | Sheet order now reads as a workflow: Settings → Data Entry → Data Collection Form → Control Charts → Monitor → Visual SPC → Capability → Dashboard → document control. |

Also new:

* **Rolling chart window.** v12.1 always plotted rows 5–204, so charts froze once
  you passed 200 samples. Charts now follow the **most recent** `Settings!F5`
  points (default 200) and keep scrolling as data arrives.
### Bugs found in v12.1 and fixed

**The Visual SPC histogram never drew any bars.** Every cell of its `BinCnt`
column (`AB7:AB26`) read:

```
=IF(AA7=NA(), NA(), COUNTIFS(...))
```

`AA7=NA()` compares a cell against the `#N/A` *error*, and any comparison
involving `#N/A` evaluates to `#N/A` — whether `AA7` holds a number or an
error. So the guard was always true-ish in the worst way: all 20 bin counts
returned `#N/A` under every condition, and the chart had nothing to plot. The
correct test is `ISNA(AA7)`. v13 does not compare against `NA()` anywhere, and
`validate_v13.py` now fails the build if that pattern ever reappears.

**The histogram bins were built from the spec limits alone.** Bin lows ran
`LSL + k*(USL-LSL)/20`, so:

* with no spec limits set, a blank cell read as `0` and all 20 bins collapsed to
  zero width at zero;
* with limits set, any reading outside tolerance fell outside the bin range
  entirely — the out-of-spec tail, the part you most want to see, was invisible.

v13 bins the actual data min/max, widens that to cover LSL and USL, then pads 5%,
so the distribution *and* both limits are always in frame.

**Its histogram only ever covered the first 200 data rows** (`$U$7:$U$206`),
so anything past row 204 of Data Entry was missing from the distribution. v13
counts the whole filtered set (`_Calc!$D$5:$D$10004`).

Note the filter cells moved: v12.1 used `C4` as a single exact date match. v13
uses `C4` as date-from and `E4` as date-to, with shift/operator/tool at `G4`,
`I4` and `K4`.

* **Capability** gained median, min, max, range, overall sigma, tolerance width,
  an In-Spec check and a plain-English verdict, and it no longer computes
  Cp/Cpk from a blank spec limit read as zero — a real bug in v12.1, where an
  empty USL/LSL evaluated to `0` and produced meaningless capability numbers.
* **Monitor** gained an all-feature status table (last value, mean, range, Cpk,
  in control, in spec, verdict) with red/green conditional formatting — the
  at-a-glance panel for a shop-floor screen.

## Sheet map

| Sheet | Purpose |
|---|---|
| Settings | Feature definitions (name, nominal, LSL, USL, unit, active) + display and monitor options |
| Data Entry | Measurements. Column H = feature 1, I = feature 2 … BE = feature 50. Row 10009+ holds the per-feature statistics block |
| Data Collection Form | Print-ready manual recording sheet |
| Control Charts | Per feature: stats panel, X chart, mR chart, histogram |
| Monitor | Folder-watch config, all-feature status table, 4 selectable chart slots |
| Visual SPC | Filtered analysis and plots |
| Capability | Cp / Cpk / Pp / Ppk with traffic lights |
| Dashboard | Single-feature summary |
| `_Calc` | Hidden filter engine for Visual SPC — do not edit |
| Document Control / Revision History / File Locations / Help | Document control |

### Yellow cells

Yellow fill + blue text = yours to type in. Everything grey is calculated.

## Setting up folder monitoring

1. Open the workbook and **save it as `.xlsm`** (macros cannot live in `.xlsx`).
2. `Alt+F11` → *File* → *Import File* → `SPC_V13_Monitor.bas`.
3. On **Settings**:
   * `F8` watch folder, e.g. `D:\CMM\exports`
   * `F9` pattern, e.g. `*.csv`
   * `F10` refresh seconds (minimum 10)
   * `F11` `Y` to move imported files into `F12` (default `archive`)
4. `Alt+F8` → `SPC_StartMonitor`.

Accepted row layouts in an incoming CSV/XLSX:

```
Date,Shift,Operator,ToolID,Cluster,F1,F2,...,Fn      <- 5 metadata fields then readings
F1,F2,...,Fn                                          <- readings only
```

A header row (no numeric fields where readings are expected) is skipped.

Macros available: `SPC_StartMonitor`, `SPC_StopMonitor`, `SPC_ImportNow`,
`SPC_RefreshAll`, `SPC_KioskMode`, `SPC_KioskStop`, `SPC_ClearData`,
`SPC_PrintForm`, `SPC_ExportReportPDF`, plus `GoTo…` navigation subs you can
attach to buttons.

## Validation

```bash
python3 validate_v13.py SPC_Calculator_v13.xlsx
```

Checks every one of the ~100,500 formulas for balanced parentheses and quotes,
that each referenced sheet exists, that only Excel-2007-era functions are used
(no `XLOOKUP`/`FILTER`/`TEXTJOIN`-style functions that would break in older
Excel or LibreOffice), that all 45 chart series and category ranges point at
populated columns, and that the chart helper chain lands on the intended
Capability columns.

**The formulas have not been machine-recalculated.** LibreOffice could not load
any `.xlsx` in the build environment, so no recalculation engine was available;
the checks above are static. Open the workbook once in Excel and press
`Ctrl+Alt+F9` to force a full recalculation, and give the charts a quick look
before issuing the document.

The workbook is formula-heavy (~100k formulas, mostly the 10,000-row Data Entry
and `_Calc` grids). It recalculates fine, but if it ever feels sluggish on a
slow machine, reduce `Data Rows Available` in the build script (`DATA_ROWS`)
and rebuild.

## Assumptions in the shipped file

* The workbook ships with **100 rows of generated demo data** across 10 features
  so every chart has something to show. Delete rows 5–104 on Data Entry (or run
  `SPC_ClearData`) before real use.
* Demo **spec limits are nominal ± 4σ of the demo data**, chosen only so the
  USL/LSL lines and histogram spikes are visible. They are not engineering
  tolerances — overwrite Settings columns D and E with your drawing values.
* Control limits use the standard individuals/moving-range constants:
  σ_within = mR-bar / 1.128, UCL/LCL = X-bar ± 2.66 × mR-bar,
  UCL(mR) = 3.267 × mR-bar.
* Dates are stored as `YYYY-MM-DD` text (unchanged from v12.1), so the Visual SPC
  date filters compare text — enter filter dates in the same format.
